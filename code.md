Frontend Code Standards calculator-frontend

1. Use semantic HTML tags and indent with 2 spaces.
2. Use camelCase for JS variables.
3. Use async/await for all backend requests and catch network exceptions.
4. Separate page rendering into functions to decouple: calculation, loading history, deletion, and rendering.
5. Prohibit frontend from performing expression calculations; all should be handled by backend APIs.
6. Git commit messages: 'feat' for adding features, 'fix' for fixing bugs.
