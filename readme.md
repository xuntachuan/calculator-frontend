Calculator Frontend
A frontend page for a calculator with front-end and back-end separation, built using native HTML, CSS, and JavaScript, which calls the back-end API via fetch.
Features: Calculator button input, sending expression requests, displaying results, viewing history, and deleting history.

## Running
Open index.html directly in a browser.
First, start the back-end service, and modify BACKEND_URL in the JS file to the back-end address.
Deployment: GitHub Pages
